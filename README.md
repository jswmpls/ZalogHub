# ZalogHub — Todo List

Тестовое задание Junior Frontend Developer.

## Стек

- React 18
- TypeScript
- Vite

## Запуск
```
npm install
npm run dev
```
Открыть http://localhost:5173

## Сборка
```
npm run build
npm run preview
```
## Функционал

- Добавление задач (пустые/из пробелов запрещены)
- Переключение выполнено/активно
- Удаление
- Фильтр: все / активные / выполненные
- Сохранение в localStorage
- Счётчик активных задач
